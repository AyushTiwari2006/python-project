# 🚗 Car Sales Data Analysis

## 📌 Project Overview
This project analyzes a car sales dataset using Python to uncover sales trends, brand performance, pricing insights, and customer preferences.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed
- Data Cleaning
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Brand-wise Sales Analysis
- Price Distribution
- Fuel Type Analysis
- Transmission Analysis
- Data Visualization

## 📈 Key Insights
- Identified the most popular car brands.
- Compared automatic and manual transmission sales.
- Analyzed fuel type distribution.
- Visualized price trends and sales patterns.

## 📂 Dataset
Car Sales Dataset (CSV)

## ▶️ How to Run
1. Clone this repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open the notebook:
   ```
   Car_Sales_Analysis.ipynb
   ```
